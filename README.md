# מיפוי המוח ודימות מוחי — ויקי הקורס

מספר הקורס: **04553505**

אתר מלווה לקורס, המיועד להתרחב לאורך הסמסטר עם הכנת שיעורים נוספים.

## תכנים נוכחיים

- סילבוס ומטלה: נושאי הלימוד, לוח המפגשים, הערכה והנחיות אתגר מיפוי המוח.
- שיעור מבוא: מצגת השיעור, 14 הרחבות ו־41 ערכי מושגים עם הגדרות, רקע ומקורות.
- שיעור 02 — מגנטיות גרעינית: 12 הרחבות, 33 ערכי מושגים חדשים ומושגים משותפים לשיעור המבוא; המחשות אינטראקטיביות לתדירות לרמור ולזווית ההטיה.

- שיעור 03 — רלקסציה: 14 הרחבות, 21 ערכי מושגים חדשים ומושגים משותפים; המחשות אינטראקטיביות להתאוששות T1 ולאקו ספין. מבוסס על מצגת בת 45 שקופיות מ־22.10.2026 שעדיין בעריכה.

למי שלא למדו פיזיקה: מסלול **פיזיקה מההתחלה** (`#physics-basics`), 11 ערכי יסוד, קישורי רקע מתוך ההרחבות והסברים מילוליים לפני הנוסחאות. המקורות כוללים הפניות מודרכות להדגמות PhET.

תוכן שיעור 02 עודכן לפי המצגת הסופית מ־22.10.2026, הכוללת 44 שקופיות. המספור וקישורי המקור הותאמו לגרסה זו. ערכי המושגים כוללים הסברים כלליים, דוגמאות, רקע מדעי והקשר ל־MRI, מעבר לנאמר בשקופיות.

הוויקי הוקם ונערך באמצעות ChatGPT. אם מצאתם אי־דיוקים או שיש לכם הערות, נא לעדכן את מרצי הקורס.

## פרסום ותחזוקה

האתר בנוי מקובצי HTML, CSS ו־JavaScript ואינו דורש התקנה או שלב בנייה.
GitHub Pages מפרסם את התיקייה הראשית של ענף `main`.

- `index.html` — מסגרת האתר והניווט הכללי.
- `styles.css` — העיצוב והתאמה למסכים שונים.
- `course.js` — פרטי הקורס, הסילבוס, המטלה וסידור ההרחבות.
- `content.js` — תכני ההרחבות ומקורותיהן.
- `wiki.js` — ערכי המושגים.
- `lesson-two.js` — הרחבות ומושגים לשיעור 02, מקורות ורשימת שיעורי הקורס.
- `lesson-three.js` — הרחבות, מושגים, מקורות והמחשות לשיעור 03.
- `wiki-app.js` — תצוגת העמודים, חיפוש וניווט.
- `feedback.js` — כתיבה ושליחה של הודעות בתוך הוויקי, עם צירוף שם העמוד והקישור אליו. הקישור בראש האתר מוביל לתיבת ההודעה בתחתית העמוד. ההודעות נשלחות למנגנון הקבלה הקיים של Google Forms ואישור הקבלה מוצג בתוך העמוד; אין מעבר ללשונית אחרת. ההודעות נשמרות בגיליון פרטי בחשבון המרצה, ואינן נשמרות במאגר הציבורי. אין להציג הצלחה על בסיס טעינת המסגרת בלבד: התוצאה בפועל מוצגת ישירות ממנגנון הקבלה. טיוטות נשמרות בזיכרון הלשונית לפי העמוד כל עוד לא מרעננים אותה.

בעת הוספת שיעור חדש, מוסיפים את נתוניו ל־`COURSE_LESSONS` וטוענים את קובץ התוכן לפני `wiki-app.js`. דף הבית, ניווט הקורס, דפי השיעורים ומילוני המושגים נוצרים מהרשימה. קישורי שיעור המבוא הקיימים נשמרים.
